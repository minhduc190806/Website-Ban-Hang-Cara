Danh Sách Các Bảng Trong Cơ Sở Dữ Liệu

  • 1. Categories (Danh mục): Id (PK), Name, Description, CreatedAt
  • 2. Products (Sản phẩm): Id (PK), CategoryId (FK), Name, Brand, Price, OldPrice, ImageUrl, Description, Stock, IsFeatured, IsNewArrival
  • 3. Customers (Khách hàng): Id (PK), FullName, Email, PhoneNumber, Address, CreatedAt
  • 4. Orders (Hóa đơn): Id (PK), OrderCode (Unique), CustomerId (FK), CustomerName, CustomerPhone, ShippingAddress, TotalAmount, Status, OrderDate
  • 5. OrderDetails (Chi tiết hóa đơn): Id (PK), OrderId (FK), ProductId (FK), ProductName, Size, Price, Quantity, SubTotal
  • 6. Admins (Quản trị viên): Id (PK), Username (Unique), Password, FullName, Role
