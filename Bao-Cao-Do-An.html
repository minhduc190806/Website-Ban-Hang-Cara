CHƯƠNG 1: TỔNG QUAN ĐỀ TÀI VÀ TÍNH CẤP THIẾT

1.1. Đặt vấn đề và tính cấp thiết

Trong kỷ nguyên công nghiệp 4.0 và chuyển đổi số bùng nổ, thương mại điện tử (E-Commerce) đã trở thành một phần tất yếu của nền kinh tế hiện đại. Tại Việt Nam, ngành thời trang và may mặc luôn chiếm tỷ trọng mua sắm trực tuyến vượt trội nhờ tính đa dạng về mẫu mã, chu kỳ đổi mới nhanh và nhu cầu tiêu dùng thường xuyên của mọi tầng lớp người dân.

Các cửa hàng thời trang bán lẻ truyền thống đang phải đối mặt với rất nhiều khó khăn và rào cản lớn: chi phí thuê mặt bằng đắt đỏ, nhân công tốn kém, phạm vi tiếp cận khách hàng bị giới hạn cục bộ trong một khu vực địa lý hẹp. Hơn nữa, việc quản lý hàng tồn kho, sổ sách và đơn hàng bằng các phương pháp thủ công thường xuyên dẫn đến tình trạng sai lệch số liệu, nhầm lẫn size số và thất thoát tài chính.

Chính vì vậy, việc nghiên cứu và xây dựng một hệ thống website thương mại điện tử bán hàng thời trang hoàn chỉnh là yêu cầu cấp thiết, giúp doanh nghiệp số hóa toàn diện quy trình kinh doanh, tiếp cận khách hàng tiềm năng 24/7 và nâng cao năng lực cạnh tranh trên thị trường.

1.2. Mục tiêu nghiên cứu của đề tài

Đồ án tập trung hiện thực hóa các mục tiêu cốt lõi sau:

  • Làm chủ nền tảng ASP.NET Core MVC (.NET 10): Ứng dụng đầy đủ các kỹ thuật lập trình hiện đại như Dependency Injection, Razor Tag Helpers, Session State Management, Asynchronous Controller.
  • Thiết kế CSDL quan hệ chuẩn mực: Xây dựng cơ sở dữ liệu trên Microsoft SQL Server đáp ứng dạng chuẩn 3 (3NF) với 6 bảng liên kết chặt chẽ.
  • Giải pháp Dual-Database Auto-Fallback: Xây dựng cơ chế thông minh cho phép hệ thống tự động ưu tiên SQL Server, nhưng nếu SQL Server chưa bật, hệ thống tự động fallback trong 2 giây sang SQLite nội bộ để đảm bảo website không bao giờ bị dừng hoạt động hoặc crash khi bảo vệ đồ án.
  • Đồng bộ hóa 100% trên Localhost: Hợp nhất toàn bộ các chức năng từ Client đến Admin thành một hệ thống duy nhất chạy trên http://localhost:5000 với các URL thân thiện, loại bỏ hoàn toàn các file tĩnh .html rời rạc.

1.3. Đối tượng và phạm vi nghiên cứu

  • Đối tượng nghiên cứu: Kiến trúc phần mềm ASP.NET Core MVC, công nghệ ORM Entity Framework Core, hệ quản trị CSDL Microsoft SQL Server, quy trình thương mại điện tử thời trang.
  • Phạm vi hệ thống:
    • Phân hệ Khách hàng: Trang chủ, xem sản phẩm, tìm kiếm, lọc danh mục, chi tiết sản phẩm, giỏ hàng Session, thanh toán đơn hàng Checkout.
    • Phân hệ Quản trị (Admin Area): Bảng điều khiển thống kê, quản lý CRUD Sản phẩm, quản lý Hóa đơn, quản lý Danh mục, cung cấp REST API.

CHƯƠNG 2: KHẢO SÁT VÀ PHÂN TÍCH YÊU CẦU

2.1. Phân tích yêu cầu chức năng hệ thống

Hệ thống được thiết kế phân định rõ ràng thành 2 phân hệ người dùng chính:

2.1.1. Phân hệ Khách hàng (Client Portal)

  • Trang chủ (Home): Trình diễn banner khuyến mãi, danh mục tính năng ưu việt, khối Sản phẩm nổi bật (Featured Products), khối Hàng mới về (New Arrivals) và pop-up voucher chào mừng.
  • Cửa hàng (Shop): Xem danh sách toàn bộ sản phẩm dạng lưới (Grid), tìm kiếm sản phẩm theo từ khóa thời gian thực, lọc sản phẩm theo nhóm danh mục thời trang.
  • Chi tiết sản phẩm (Detail): Xem thông tin chi tiết, ảnh lớn, chọn Size (S/M/L/XL), điều chỉnh số lượng mua, hiển thị khối Sản phẩm tương tự dàn hàng ngang 4 sản phẩm cùng loại.
  • Giỏ hàng (Shopping Cart): Lưu trạng thái bằng Session, thay đổi số lượng, xóa từng món, nhập mã giảm giá MINHDUC50 giảm ngay 50%, tính tổng thanh toán tức thì.
  • Thanh toán (Checkout): Nhập thông tin người nhận, chọn phương thức thanh toán (COD hoặc Chuyển khoản), sinh mã đơn hàng tự động và lưu dữ liệu vào CSDL.
  • Xác thực tài khoản (Account): Đăng ký khách hàng mới, đăng nhập tài khoản, ghi nhớ phiên làm việc và hiển thị tên người dùng trên thanh Menu.

2.1.2. Phân hệ Quản trị viên (Admin Area)

  • Bảng điều khiển (Dashboard): Thống kê trực quan số lượng sản phẩm, danh mục, đơn đặt hàng và tổng doanh thu bán hàng.
  • Quản lý Sản phẩm (CRUD): Danh sách sản phẩm có phân trang, chức năng Thêm mới sản phẩm có upload ảnh, Sửa sản phẩm, Xóa sản phẩm trực tiếp từ CSDL.
  • Quản lý Hóa đơn (Orders): Xem danh sách tất cả các đơn đặt từ phía khách, xem chi tiết từng mặt hàng trong đơn (Size, số lượng, đơn giá, tổng tiền), cập nhật trạng thái đơn (Chờ xử lý, Đang giao, Đã hoàn thành, Đã hủy).
  • Cung cấp RESTful API: Endpoint /api/products hỗ trợ các phương thức GET, POST, PUT, DELETE trả về dữ liệu định dạng JSON chuẩn.

2.2. Biểu đồ Use Case hệ thống

Danh sách Tác nhân (Actors) và Vai trò:

• Khách hàng (Guest / Customer): Tìm kiếm, xem chi tiết, quản lý giỏ hàng, đặt hàng, quản lý tài khoản cá nhân.

• Quản trị viên (Administrator): Đăng nhập hệ thống quản trị, xem báo cáo thống kê, thực hiện các thao tác CRUD dữ liệu sản phẩm, danh mục và cập nhật đơn hàng.

CHƯƠNG 4: CÀI ĐẶT VÀ TRIỂN KHAI HỆ THỐNG

4.1. Kiến trúc CSDL Kép (Dual-Database Auto-Fallback)

Đây là kỹ thuật sáng tạo độc đáo trong đồ án giúp hệ thống luôn hoạt động ổn định trên mọi môi trường máy tính khác nhau: 

// MinhDucWeb/Program.cs
bool useSqlServer = false;
if (provider.Equals("SqlServer", StringComparison.OrdinalIgnoreCase))
{
    try {
        var connBuilder = new SqlConnectionStringBuilder(sqlServerConn) { ConnectTimeout = 2 };
        using var testConn = new SqlConnection(connBuilder.ConnectionString);
        testConn.Open();
        useSqlServer = true; // Kết nối SQL Server thành công
    } catch {
        useSqlServer = false; // Tự động kích hoạt CSDL SQLite dự phòng
    }
}

builder.Services.AddDbContext<ShopDbContext>(options => {
    if (useSqlServer)
        options.UseSqlServer(sqlServerConn);
    else
        options.UseSqlite(sqliteConn);
});

100% các kịch bản kiểm thử cốt lõi đều đạt kết quả xuất sắc. Hệ thống vận hành mượt mà, thời gian phản hồi nhanh dưới 1.2s, không phát sinh lỗi rò rỉ dữ liệu.

CHƯƠNG 6: KẾT LUẬN VÀ HƯỚNG PHÁT TRIỂN

6.1. Những kết quả đạt được

Đồ án đã hoàn thành xuất sắc các yêu cầu đặt ra ban đầu:

  • Xây dựng hoàn chỉnh website thương mại điện tử chuyên nghiệp với giao diện thời trang Cara Store hiện đại, chuẩn Responsive trên PC, Tablet và Mobile.
  • Áp dụng thành công mô hình MVC trên nền tảng ASP.NET Core (.NET 10) và Entity Framework Core.
  • Thiết kế hệ CSDL quan hệ 6 bảng chuẩn 3NF đảm bảo tính toàn vẹn tham chiếu.
  • Hiện thực hóa cơ chế kết nối CSDL kép Dual-Database thông minh (SQL Server + SQLite).
  • Hợp nhất 100% hệ thống trên máy chủ Localhost với các tuyến đường dẫn thân thiện.

6.2. Hạn chế và hướng mở rộng trong tương lai

  • Tích hợp cổng thanh toán trực tuyến: Kết nối trực tiếp API VNPAY Sandbox hoặc MoMo QR Code để thanh toán tự động qua ngân hàng.
  • Dịch vụ gửi Email tự động: Cấu hình dịch vụ SendGrid hoặc SMTP để tự động gửi hóa đơn điện tử vào hòm thư khách hàng khi đặt hàng thành công.
  • Phát triển Ứng dụng Di động: Xây dựng ứng dụng Flutter/React Native kết nối trực tiếp với REST API /api/products đã xây dựng sẵn.
